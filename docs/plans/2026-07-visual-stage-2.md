# «Реальна гра»: візуальний етап 2 (гілка `render/pixi`)

## Контекст

Перший захід (виконаний: `78f831f`+`a1b4af7`) повернув гру в темний стиль «Ґримуар», але
вона все ще виглядає як прототип: emoji-бійці, плоске коло-казан, порожній фон, юнікод-
гліфи різної якості в UI, зілля = символ у квадратику. Мета цього заходу — щоб гра
виглядала як **реальна гра**, без художника.

**Ключовий ресурс, знайдений розвідкою:** `@iconify-json/game-icons` (v1.2.4, CC-BY-3.0)
— ~4000 гравюрних іконок game-icons.net **доступні через npm** (зовнішні сайти з
контейнера заблоковані, npm працює). Дизайн-док §8 прямо рекомендує game-icons.net як
джерело в стилі «Ґримуар». Це відкриває: символи стихій, монстрів, казани, колби, декор.

**Рішення власника (по пунктах):**
1. Бійці — **відкладено** («придумаємо пізніше», emoji лишаються).
2. Казан — **код + код-VFX** (без арт-спрайтів).
3. Фон арени — **багатший кодовий**.
4. Іконки UI — **все на game-icons**.
5. Інгредієнти — **замінити овочі на гравюру** (єдиний стиль).
6. Колби зіль — **так, базова комбінаторна версія**.
7. Джус — **середній пакет**.
8. Обгортка (favicon/тайтл/fade-in) — **так**.

## Крок 1 — Іконна система game-icons (фундамент для всього далі)

- `npm i -D @iconify-json/game-icons` (SVG path data, viewBox 512×512; у бандл потрапляють
  лише вибрані path-рядки — кілобайти, не весь пакет).
- **`src/ui/icons.ts`** — фабрика inline-`<svg>` для DOM: `iconEl(name, className)`,
  `fill="currentColor"` → колір задає CSS (золото/пергамент/рідкість). Кураторська мапа
  `семантичне ім'я → iconify-ключ` в одному місці.
- **`src/render/icon-textures.ts`** — той самий словник для Pixi: SVG-рядок з запеченим
  кольором → `data:image/svg+xml` → `Assets.load` → `Texture`, кеш за (name, color, size).
  (Патерн аналогічний `fx-textures.ts`.)
- Замінити юнікод/emoji на гравюру:
  - символи стихій на кільцях казана (`cauldron-scene.ts`, зараз 🜂🜃🜄🜛🜍 текстом);
  - таби Brew/Potions/Lab (`lab-panel.ts` TAB_ICONS);
  - іконки інгредієнтів — переписати `src/ui/ingredient-icons.ts` з овочів-PNG на
    game-icons (трут→гілка/хмиз, черепок→уламок, вогнекорінь→корінь, ртуть→крапля
    металу, вода→крапля). Craftpix-овочі йдуть з UI (пак лишається в репо);
  - слоти мутацій/paper-doll і монета/попіл у HUD — де є пряма відповідність.
- Підбір конкретних іконок — контактним листом (як робив з овочами), фінальний вибір
  на око під час реалізації.
- `docs/CREDITS.md`: рядок game-icons.net (CC-BY 3.0 — автори Lorc, Delapouite та ін.;
  атрибуція обов'язкова, це вже зафіксовано в дизайн-доку «рядок в титрах!»).

## Крок 2 — Казан кодом + VFX варки (`cauldron-scene.ts`)

- Тіло казана `Graphics`-примітивами замість плоского кола: округлий котел, широкий
  обід-еліпс, три ніжки, золотий відблиск-дуга; поверхня рідини — еліпс зі смарагдовим
  градієнтом (2–3 шари альфи) і синус-хвилею по краю.
- Пара: 3–4 частинки, що повільно піднімаються з розчиненням (як embers у бою).
- **Джус варки (частина «середнього пакета»):** перед розкриттям результату кільця
  плавно гальмують до зупинки (~0.5с пауза-перед-розкриттям, easeOut замість
  раптового burst), тоді: успіх → золотий спалах + сплеск іскор із казана; провал →
  короткий screen shake сцени + темний «пшик» пари. `prefers-reduced-motion`
  поважається (перевірка вже є).

## Крок 3 — Фон арени (`battle-scene.ts`)

Кодова «лабораторія алхіміка», 2–3 шари глибини (все `Graphics` + `icon-textures`):
- дальній шар: силуети кам'яних арок/стіни (темніше за фон, ледь видимі);
- середній: полиця з гравюрним декором дуже низької альфи (книги, черепи, колби з
  game-icons — 3–4 спрайти);
- підлога: велике **руне коло** під ареною (кільця + вписані лінії + дрібні гравюрні
  руни по колу) — замінює/підсилює поточний trodden-еліпс;
- віньєтка по краях сцени (радіальний градієнт, канвас-генерована текстура);
- свічки лишаються; бійці-emoji лишаються (рішення «пізніше» — але тепер на рунному
  колі й з декором вони виглядатимуть доречніше).

## Крок 4 — Комбінаторні колби зіль (`src/ui/potion-icon.ts`, новий)

Базова версія системи з дизайн-доку («силует × колір рідкості × штамп»):
- 3 силуети колб із game-icons за грейдом: настойка (маленька кругла), еліксир
  (конічна), великий еліксир/квінтесенція (орнаментна);
- заливка «рідини» кольором рідкості через `var(--rar)` (інфраструктура rar-класів
  уже є в `lab-panel.css`);
- штамп-символ стихії маленькою гравюрою поверх колби;
- використати в: полиці зіль (`potion__tile`), слотах мутацій, банері результату варки.
- Це DOM/inline-SVG композиція — `data/*.json` не чіпаються, рідкість-кольори лишаються
  в `rarity-visuals.ts`.

## Крок 5 — Джус решти UI («середній пакет», без звуку)

- Плавні переходи вкладок (CSS fade/slide ~150мс на `.panel`).
- Screen shake на поразку в бою — легкий CSS-клас на рамку `.scene` (Pixi-шейк усередині
  сцени вже є, це доповнення на рамці).
- Стартовий fade-in застосунку (клас після завантаження шрифтів) — прибирає «стрибок»
  незастилізованого контенту.
- (Near-miss на кільцях і політ монет у HUD — відхилено: «повний пакет» не обрано.)

## Крок 6 — Обгортка

- **Favicon**: SVG-колба (золото на темному) як `data:`/файл у `index.html` — замість
  дефолтного Vite.
- **Тайтл**: гравюрний декор-розділювач біля «Lucky Alchemist» в `app-shell.ts`.
- Meta theme-color під фон гри.

## Порядок виконання

1 (іконна система) → 2 (казан+джус варки) → 3 (арена) → 4 (колби) → 5 (джус UI) →

## Поза скоупом (зафіксовано)

- **Бійці-спрайти** — окремий захід («придумаємо пізніше»); якщо знайдеш анімований
  пак у стилі — кажи, архітектура заміни точкова.
- Звук (Етап 2), near-miss, політ монет — не зараз.
- Craftpix-сирці в git-історії — не чіпаємо (рішення власника).
- Ілюстровані фони/AI-ген — не зараз (обраний кодовий шлях).
