# Lucky Alchemist — гейм-дизайн

> Робоча назва проєкту: **Lucky Alchemist**. Фінальна назва потребує окремої перевірки
> перед релізом (сторси, домени, товарні знаки) — див. розділ 9. Джерело: авторський
> документ `fateforge-plan-v2.md` (гейм-дизайн-рішення власника проєкту), адаптований і
> впорядкований тут українською. Технічна реалізація цих механік описана окремо в
> [ARCHITECTURE.md](ARCHITECTURE.md); порядок розробки — в [ROADMAP.md](ROADMAP.md).

## 1. Концепція

**Міф.** Ти — алхімік, який варить власні мутації. Кожна варка — ставка: інгредієнти
летять у казан, три кільця символів обертаються навколо булькаючого зілля. Збіглися —
реакція вдалася, ні — усе згоріло. Вдалий відвар можна перегнати ще і ще... поки колба не
лопне. Випий те, що зварив, — і йди в бій.

**Формула проти класичних Forge Master-кликерів:** там — «крути і чекай», тут — «став,
ризикуй, вирішуй, коли зупинитись». Удача — не пасивний рандом, а матеріал, з яким гравець
працює усвідомлено.

### Три акти варки (ядро цикла)

1. **Варка (слот).** Інгредієнти = ставка. Три концентричні кільця символів у казані;
   збіг по лінії = результат, рідкість — за комбінацією. Провал = інгредієнти в попіл.
   Візуально це **не** повинно читатись як слот-машина — критично для модерації порталів.
2. **Дистиляція (push-your-luck).** Кожен цикл перегонки: шанс підняти ґрейд
   (настойка → еліксир → великий еліксир → квінтесенція) або втратити все — колба
   лопається. Головне рішення гри.
3. **Каталізатор (джекпот).** Рідкісна реакція дає унікальний артефакт і скалку
   філософського каменя. Зібраний камінь — мета епохи.

### Дека інгредієнтів (гібрид)

База (трави, кістки, руда епохи) — паливо варки. Рідкісні **добавки-модифікатори**
змінюють склад символів на кільцях: вогняний корінь додає символи вогню, ртуть — символи
металу. Гравець збирає свій рандом; закупівля інгредієнтів = вибір білда, а не грінд.

## 2. Core loop

```
Інгредієнти → ВАРКА (кільця) → мутація/еліксир → ДИСТИЛЯЦІЯ (ризик)
     ↑                                                    ↓
  офлайн-дохід + попіл + золото  ←  АРТЕФАКТИ  ←  випити мутацію (екіпірування)
     ↑                                                    ↓
  апгрейди лабораторії  ←  золото/інгредієнти  ←  стейджі 1-1 … 5-20
```

- **Короткий цикл** (5–15 сек): варка → збіг → результат.
- **Середній** (5–15 хв): накопичити на білд добавок → дистиляція → новий ґрейд → стейдж.
- **Довгий** (дні): епоха → новий свіч правил → престиж.
- **Idle:** автоварка (апгрейд), офлайн-накопичення базових інгредієнтів.

## 3. Станції лабораторії (міні-ігри)

Порядок нижче = порядок розробки (див. ROADMAP.md). MVP = варка + дистиляція.

1. **Варка + Дистиляція** — MVP, ядро (Етап 1).
2. **Просіювання попелу** (скретч, епоха 1) — зчищається шар з ефектом (canvas-маска),
   дістаються цільові інгредієнти з провалів. **Це підлога економіки**: завжди дає мінімум.
3. **Круг трансмутації** (рулетка, епоха 2) — кладеш предмет (можна екіпірований!) у центр
   кола стихій; стрілка вирішує: помножити ×2/×5 чи розчинити. Push-your-luck зі ставкою
   майном. Апгрейд «страхування»: при провалі повертається скалка для перековки зі знижкою.
4. **Кості духів** (епоха 3) — торг із духами-постачальниками: дублі на кості за ціну
   партії інгредієнтів.
5. **Капельна колона** (плінко, епоха 4) — масова переплавка дублів: краплі падають крізь
   скляний лабіринт у колби різної якості (фізика matter.js).
6. **Колесо фортуни** — поза епохами, 1 безкоштовний спін на день.
7. **Тижневий сід-челендж** — фіксований сід PRNG на всіх гравців, порівняння результатів
   без бекенда.

**Виключено назавжди:** блекджек із першої версії задуму — не маскується під алхімію,
зайва механіка.

## 4. Герой і глибина інтересу

**Алхімік-самомутант.** 6 слотів мутацій: кінцівки/зброя, шкіра/броня, очі/крик,
серце/HP, залози/швидкість, ядро/талісман удачі (впливає на бій і на ваги символів
казана). Візуально — paper-doll: базовий силует + шари-оверлеї мутацій.

### Шари інтересу за горизонтами (головний фокусv2)

- **Хвилини:** соковитість казана (анімації, частинки, звук).
- **Години 1–5:** дека добавок — гравець формує свій рандом.
- **Години 5–20:** синергії. Теги мутацій (вогонь/камінь/звір/тінь), 3 одного тега =
  сет-ефект. **Каталізатори** = рідкісні «джокери», що змінюють правила казана:
  «кільця крутяться довше, але рідкісні символи ×2», «кожна 5-та варка безкоштовна»,
  «тріщини дають попіл ×10». Білдоутворення в дусі Balatro.
- **Дні:** епохи міняють ПРАВИЛА, не шпалери: античність = 4-те кільце стихій;
  середньовіччя = прокляття (провал вішає дебафф-модифікатор до варки очищення);
  індустрія = автоматизація і варка партіями; майбутнє = квант-символи (рахуються за два).
- **Тижні/місяць:** престиж, колекції, тижневі сіди, (потім) гомункул.

**Бої:** автобатлер по стейджах (числова симуляція + проста анімація), 5 епох × 20
стейджів. Перемога = золото, інгредієнти, ключі. Рідкості: Common → Uncommon → Rare →
Epic → Legendary → Quintessence.

**Еліксири-расходники** (етап 5): банки баффів на N боїв — тактика «коли стартувати».

**Колекції:** журнал алхіміка — все, що коли-небудь зварено; повна сторінка епохи =
перманентний баф.

**Престиж «Велике Бажання»:** добровільний скид за скалки філософського каменя —
перманентні глобальні бафи. Відкривається на етапі 5, коли є контент.

## 5. Економіка і баланс

**Валюти:** базові інгредієнти (паливо), добавки (модифікатори, дека), золото (магазин,
апгрейди), попіл (з провалів → переплавка в базу з поверненням), скалки каменя
(престиж/артефакти).

**Принцип ризику:** висока дисперсія + шитка підлога.
- На стейджі можна реально «прогоріти» — це і є емоція, яка чіпляє.
- Пол: просіювання попелу завжди дає мінімум + базові інгредієнти капають з часом
  (і офлайн). Застрягти без ходу неможливо; гравець бачить «я викарабкався», не механіку.
- Жорсткі ставки (екіпірованим) відкриваються з епохи 2 + апгрейд-страхування — захист
  новачка зважений.

**Правила балансу:**
- Усі ваги і ціни — у JSON-конфігах (`src/data/`), не в коді.
- Експоненційні ціни апгрейдів (`base × 1.15^level`).
- **Econ-sim обов'язковий з Етапу 1:** прогін 10 000+ варок на core-коді; ключова
  метрика — не середній RTP, а **% симульованих гравців, застряглих понад N годин**.
- Seeded PRNG (sfc32/mulberry32), сід у сейві: відтворюваність, тижневі челенджі,
  захист від save-scumming.

## 6. Право, рейтинг, монетизація

- **Назву змінити:** «Lucky Forge» зайнято (гра TapNation + казино-сайт) — потрібне нове,
  перевірити перед фіксацією: сторси, Steam, домени, товарні знаки.
- **Механіки не захищаються авторським правом** — надихатись структурою Forge Master /
  Balatro / подібних roguelike-білдерів законно. Заборонено копіювати: арт, назви, UI,
  тексти. Портали судяться жорстко: «занадто схоже» відхиляють як клон.
- **Жодних реальних грошей і виводу.** Віртуальні ресурси тільки з ігри.
- **Монетизація = rewarded-реклама через SDK порталу** (безкоштовна варка, подвоєння
  знахідки, страхування колби). Власних платежів немає.
- М'які механіки заботи: без FOMO-таймерів, лічильник сесії.

## 7. Ризики гейм-дизайну

| Ризик | Мітигація |
|---|---|
| Контент набридне за 20 хвилин | дека добавок + каталізатори-джокери + свічі епох — правила міняються, не тільки числа |
| Новачок програв усе і пішов | жорсткі ставки з епохи 2, страхування, шитка підлога (попіл + офлайн-дохід) |
| Економіка: застій або злам | econ-sim у CI, метрика «% застряглих», усі числа в JSON |
| Модерація порталів | ніякої казино-лексики і візуалу слот-машини; кільця, не барабани; прочитати гайди до сабміту |
| Клон-звинувачення | свій візуальний язик (Ґримуар), своя механіка (дека+дистиляція), нова назва |

## 8. Мистецтво і звук (без художника)

**Стиль «Ґримуар»:** темний тон, гравюрний контур, світіння; палітра золото #C9A227 /
смарагд #3FA372 / пурпур #6E4B8E на #100D0A. Шрифти: IM Fell English SC (заголовки) +
EB Garamond (текст) — Google Fonts (OFL). Неон-токен = скетч для епохи майбутнього.

**Чотири шари виробництва:**
1. Код і шейдери: кола, стихії, глоу, частинки (Pixi).
2. Комбінаторика: зілля = силует колби × колір рідкості × штамп × частинки; мутації =
   оверлеї paper-doll. Сотні предметів із ~20 примітивів.
3. Бібліотеки: game-icons.net (гравюрний стиль, **CC-BY — рядок в титрах!**), юнікод-гліфи
   алхімії/планет для кілець, Kenney (CC0) для UI-заготовок.
4. Соковитість = код: тайминги сповільнення кілець, near-miss (тільки візуально, без
   викривлення реальних шансів), пауза-перед-розкриттям, screen shake.

**Звук:** freesound.org — перевіряти ліцензію кожного файлу (CC0 ок; CC-BY = атрибуція;
CC-BY-NC не можна — гра з рекламою комерційна).

**AI-генерація картинок:** тільки опція для фонів епох; перед використанням прочитати
правила порталу про AI-контент.

## 9. Платформа і план сабміту

Веб-портали: CrazyGames, Poki, YouTube Playables (+ itch.io для фідбеку). Poki забороняє
гемблінг-тематику — саме тому скін алхімії, а не казино. Бюджет: первинне завантаження
≤ 5 МБ; асети епохи 2+ — ліниво.

Детальний план розробки до сабміту — у [ROADMAP.md](ROADMAP.md).
