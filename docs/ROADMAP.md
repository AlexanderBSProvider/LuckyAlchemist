## Етап 0 — Фундамент

**Мета:** робочий скелет проєкту, на якому не соромно ганяти CI, з мінімальним
end-to-end зрізом (стан зберігається/завантажується).

- ✅ Git, Vite (vanilla-ts), TypeScript strict (project references), Vitest, ESLint
  (flat config, typescript-eslint strict+stylistic), Prettier, `.editorconfig`.
- ✅ GitHub Actions CI: lint → format check → typecheck → test (+coverage) → build → econ-sim.
- ✅ `CLAUDE.md` з архітектурними правилами проєкту.
- ✅ Документи: `GAME-DESIGN.md`, `ARCHITECTURE.md`, цей `ROADMAP.md`, мапа курсу.
- ✅ `core/rng.ts` — seeded PRNG (sfc32) + тести (20 тестів).
- ✅ `core/save/` — схема сейву v1, серіалізація, реєстр міграцій + тести (10 тестів).
- ✅ `store/` — власний store (getState/dispatch/subscribe) + event bus + тести (30 тестів).
- ✅ `platform/` — інтерфейс `PlatformAdapter` + `LocalAdapter` (localStorage) + тести (6 тестів).
- ✅ App shell — `index.html` + `main.ts`, мінімальний DOM-екран у стилі «Ґримуар»
  (CSS-змінні палітри, кнопка Save, індикатор стану).
- ✅ Уроки курсу, модулі 0–2 (`docs/course/01`–`03`).

**Definition of Done:** гра відкривається (`npm run dev`), зберігає і відновлює стан
через localStorage, `npm run lint && npm run typecheck && npm run test && npm run build`
проходять без помилок (66/66 тестів), CI зелений. **Досягнуто.**

**Бюджет білда на цьому етапі:** не вимірюється як вимога (немає Pixi/асетів) — контрольна
точка з Етапу 1. Фактична збірка Stage 0: ~58 КБ JS + ~2 КБ CSS (гзіп ~15 КБ) — з великим
запасом під бюджет 5 МБ.

## Етап 1 — MVP-петля ⬜

**Мета:** петля «варка → мутація → бій → апгрейд» грається і її можна дати друзям.

- ✅ Варка: 3 концентричні кільця символів, гібрид-дека (база = паливо, добавки = модифікатор
  ваг символів), JSON-таблиці ваг для епохи 1.
- ✅ Дистиляція: push-your-luck ґрейди (настойка → еліксир → великий еліксир → квінтесенція).
- ✅ 6 слотів мутацій (paper-doll), інвентар.
- ✅ 10 стейджів автобатлера (числова симуляція; бій іде автоматично кожні
  `battle.json.autoIntervalSeconds` секунд — драйвер у `main.ts`, композиція
  «сцена-автобатлер зверху, керування знизу»).
- Просіювання попелу: 🔶 кнопка є, canvas-скретч — ні.
- ✅ 5 апгрейдів лабораторії.
- ✅ `tools/econ-sim.ts`: реальний прогін (450 боїв/год з `battle.json`), метрика
  «% застряглих гравців» (з автобоєм метрику варто переозначити — «застряг» тепер
  означає «сидів на стіні 5+ год», що для idle-стіни очікувано).
- ✅ PixiJS-рендер (спершу збудований на PixiJS, перенесений на Three.js, і на цій гілці
  (`render/pixi`) реверснутий назад — див. [THREEJS-MIGRATION.md](THREEJS-MIGRATION.md) і
  `ARCHITECTURE.md` §6): бойова сцена-автобатлер (арена, руно-кола, вуглинки,
  clash-анімація) + казан і кільця у вкладці «Казан»; CSS-стиль «Ґримуар» на інтерфейсі.
- ✅ Візуальна ре-тема «Ґримуар» (повернення до `GAME-DESIGN.md` §8 після «candy»-дрейфу):
  темна ритуальна арена зі свічками, контрастні кільця казана, self-hosted шрифти
  IM Fell English SC / EB Garamond (@fontsource, OFL), slash-FX з craftpix-паку в
  clash-анімації (ліниве завантаження), іконки реагентів у деці варки; атрибуція —
  [CREDITS.md](CREDITS.md). Урок курсу: [course/04-pixi-render.md](course/04-pixi-render.md).

**DoD:** повна петля грається з першого екрана до апгрейду без заглушок; econ-sim зелений
у CI на реальних формулах.

## Етап 2 — Соковитість і утримання ⬜

- Звук (Howler.js), частинки, «майже влучив», screen shake.
- Журнал алхіміка (колекції зварених предметів).
- Щоденне колесо фортуни + тижневий сід-челендж (фіксований PRNG, порівняння без бекенда).
- Теги мутацій і сет-ефекти (3 одного тега = бонус).
- Онбординг перших 5 хвилин.

## Етап 3 — Епоха 2 і жорсткий ризик ⬜

- Система епох: свіч правил (античність = 4-те кільце стихій), не просто нові шпалери.
- Круг трансмутації: ставки екіпірованим майном + апгрейд-страхування.
- Стейджі 11–30.
- Офлайн-дохід.

## Етап 4 — Портали ⬜

- `PokiAdapter`, `CrazyGamesAdapter` поверх `PlatformAdapter`.
- Rewarded-реклама (безкоштовна варка, подвоєння, страхування колби).
- Бюджет білда ≤ 5 МБ первинного завантаження — вимірюється і фіксується тут щозбірки.
- Лінива підвантаження асетів епохи 2+.
- Сабміт на Poki (ітерації по фідбеку рев'ю) + itch.io.

## Наскрізні вимоги (діють з моменту, коли з'являється відповідний код)

- Жодна формула не потрапляє в `core/` без юніт-тесту в тому ж коміті.
- Жоден числовий баланс не хардкодиться — тільки `src/data/*.json` + Zod-схема.
- `npm run econ-sim` — зелений у CI з Етапу 1 після кожної зміни балансу.
- Сейв — версійований; зміна форми стану = нова міграція + round-trip тест.
